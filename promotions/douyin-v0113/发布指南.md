# 数字进化 · 抖音首篇图文包

这套内容用于介绍 v0.11.3 Windows 试玩原型，目标是吸引对数字合成、战斗与撤离感兴趣的玩家，并收集真实反馈。素材已制作，尚未代为发布到抖音。

## 直接使用

1. 解压完整宣传包，先双击 `预览.html` 查看轮播顺序。
2. 在抖音选择图文发布，按 `images/` 中的 **01 → 08** 顺序选择八张 PNG。封面选择 `01-cover.png`。`预览总览.png` 只是检查用的拼版，不作为轮播页上传。
3. 从 `发布文案.txt` 复制推荐标题、正文与话题。先预览平台裁切，确保标题和底部“Windows试玩版”仍完整；八张图均为3:4，1086 × 1448像素。
4. 如需配乐，可选平台内可用的轻电子或街机节奏音乐。确认画面、文案与下载入口后，再由账号所有者发布。
5. 发布后可使用文件中的置顶评论与回复草稿。提到试玩地址时，使用**实际的新版发布页**，避免只发仍显示旧版的仓库首页。

推荐标题：**我把2048做成了搜打撤**。

## 宣传节奏

第一篇先发这一套概念介绍，收集玩家最感兴趣的武器、对玩法的疑问，以及是否愿意在电脑上试玩。无需在第一篇塞入完整开发历史和所有技术指标。

后续可按真实素材安排，每次只讲一个主题：

- **武器篇**：录同一场景下狙击枪与大剑的实际操作，让观众说出更想玩的类型。
- **决策篇**：展示一次真实的“继续搜箱／立即撤离”选择，交代当时装备、收益与风险。
- **更新篇**：有了实际反馈并完成修改后，再展示“改了什么、改前后如何”。保留真实评论的隐私，不编造反馈、玩家人数或数据。

发布后，优先记录能看到的图文浏览表现、有内容的评论、明确的试玩意愿、实际试玩与有效反馈。不同账号能看到的后台指标可能不同；点赞数不等于实际试玩人数。时间与频率可结合自己的账号数据调整，这套内容不承诺特定流量。

## 文件说明

- `images/`：八张按顺序上传的成品PNG。
- `发布文案.txt`：标题、正文、话题、置顶评论与常见回复。
- `预览.html`：双击可看全部成品图片；PNG已包含文字，不依赖本地字体。
- `assets/`：游戏实际截图与地图示意源图。
- `source/carousel.html`：第2—8张的可编辑排版源文件。修改后需重新导出PNG再上传。
- `source/capture-provenance.json`、`source/layout-checks.json`：演示来源及排版检查记录。
- `source/capture.cjs`、`source/render.cjs`：本次制作使用的自动化脚本，普通发布不需要运行。

所有素材仅用于本项目的宣传制作；没有使用其他游戏角色、截图或第三方品牌标识。
