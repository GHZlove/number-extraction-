## v0.9.1 数字溢出修复

用户在大窗口下发现 1024、2048、4096 超出方块。原字号使用视口宽度 `vw`，方块却有最大宽度，因此文字放大后失去边距。现在每个方块建立行内尺寸容器，字号使用 `cqi` 跟随当前方块；一/二位数、三位数、四位数分别使用方块宽度的 56%、40%、31%。删除断点中的固定字号，保持完整白字，不依靠裁切隐藏溢出。

存档键、格式和数据目录保持兼容 v0.9.0；请退出旧 EXE 再启动新文件。原生回归检查逐一测量十二个数字的真实文字边界，覆盖七组窗口与缩放组合，并要求左右边距至少为方块宽度的 9%。

## 六种新增武器

原有十四类保留，新增武器也参加随机掉落、武器工坊解锁和永久打造。

| 武器 | 实际机制 | 工坊解锁等级 |
| --- | --- | --- |
| 重型左轮 | 低射速、精准弹丸、较强击退 | 1 |
| 双管霰弹枪 | 两次短间隔齐射，每次四弹丸；八弹丸共用一次攻击伤害预算 | 2 |
| 能量手枪 | 较慢的大能量弹，穿透两个不同目标，墙体仍拦截 | 2 |
| 火焰喷射器 | 短程连续散射，自带持续燃烧，可另选一种附魔 | 3 |
| 火箭筒 | 较慢重弹、大范围爆炸；命中或达到射程时只爆炸一次 | 5 |
| 战斧 | 朝向限定的宽弧近战、自带流血、较强击退 | 2 |

枪种、数字差、品质和打造等级继续影响击退；护甲、墙体、首领抗性仍生效。未附魔白品 Lv.1 的数字伤害比例不变，霰弹和连发不会给每发重复计算完整伤害。武器有不同弹道、轮廓与合成音效；声音默认关闭。

## 十二种附魔

每把武器最多选择一种附魔。火焰喷射器的燃烧和战斧的流血属于武器固有效果；同类状态刷新，不无限叠加。Lv. 指武器打造等级。

| 附魔 | 效果与限制 |
| --- | --- |
| 吸血 | 按实际扣除的生命回复，单次有上限，不从尸体/过量伤害刷血 |
| 闪电 | 连锁至最多两个不同且可见的附近敌人，有触发冷却，不递归连锁 |
| 眩晕 | 短暂打断攻击，首领时长降低，有触发冷却 |
| 毒雾 | 命中位置形成有限时长毒区，半秒结算一次，受墙体约束 |
| **烈焰 · 新增** | 燃烧三秒，半秒一次持续伤害；保留较强施加快照，刷新不重置结算节拍 |
| **寒霜 · 新增** | 普通敌人移速降至 55%，首领降至 80%；三次有效施加触发短冻结，有独立冻结冷却 |
| **流血 · 新增** | 四秒持续伤害，绕过护甲吸收但不删除护甲耐久；首领伤害抗性仍生效 |
| **破甲 · 新增** | 直接削减护甲耐久并施加三秒易伤；普通敌人 +12%，首领 +6% |
| **爆裂 · 新增** | 直接击杀时对周边可见敌人造成爆炸伤害，有冷却，二次伤害不再引发连锁 |
| **暴击 · 新增** | 命中时有概率追加基础命中伤害的 50%；Lv.1 概率 20%，每级再增两个百分点，有判定冷却 |
| **重力 · 新增** | 将周边可见敌人向命中位置拉近；不能穿墙，首领位移降为四分之一，有冷却 |
| **回能 · 新增** | 有效命中回复 3+Lv. 点过载能量，最高 100，有冷却，不从尸体刷取 |

持续伤害按施加时的数字与品质计算，不会因切枪或随后合成而突然升级；二次伤害不会再次触发附魔。首领的伤害、控制和位移抗性分别处理，避免永久控制或爆炸递归。
