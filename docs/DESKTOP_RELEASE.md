Number Extraction v0.10.0 · Windows x64 preview

- Persistent equipment warehouse: extracted weapons, armour and laser attachments are stored with rarity, level, enchantment and remaining armour durability. Equipment no longer also pays out as currency/materials. Issued starter, forged starter and trial gear are excluded.
- Warehouse starts with 24 slots, upgrades by 12 per level to 144, and preserves excess extraction gear in a pending area. Select stored gear for the next raid, repair armour or explicitly recycle equipment. Deployment withdrawals are saved before the raid starts; a failed save prevents withdrawal. Brought-in warehouse gear is lost on failed extraction, while unselected stored gear remains safe.
- Nine bosses, six added: Storm Sovereign, Frost Core Warden, Shadow Reaper, Furnace Regent, Gravity Singularity and Brood Mother. New mechanics include warned cross lightning, temporary slowing fields, moving annular attacks, directional cleaves, bombardments, limited turrets/swarms, gravity wells and add-dependent boss healing. Half-health phases, interruption rules, safehouse protections and distinct weapon/enchantment rewards are implemented.
- New warehouse and boss codex shelter tabs; choose an eligible tracking target before deployment. Four map families use difficulty-appropriate boss pools. Existing colourful terrain, white homepage, 20 weapons, 12 enchantments, remnant coins and unlimited resource storage are retained.
- v0.9 progress migrates to an isolated v0.10 save key, preserving original data. JSON import/export and backups support schema 4 and a 512KB limit. Equipment that older versions already converted into resources cannot be reconstructed; existing resources are preserved.
- Download `NumberExtraction-0.10.0-Windows-x64.exe`. Finish your current raid and exit the old game before launching the new EXE. No Python, Node.js, local server or separate browser is required. F11 / Alt+Enter toggles fullscreen.
- 233 automated cases pass, including 18 new warehouse and 17 new boss cases. Native checks include seven layouts/zoom settings, warehouse/codex/inventory navigation, movement/merging, pause, progress and stored-equipment persistence across restart and execution of the final portable EXE. Screenshots and SHA256 are attached. Long-term economy balance and hardware performance still need playtesting.
- This preview is unsigned; Windows may show an unknown-publisher prompt. Keep security protections enabled.
