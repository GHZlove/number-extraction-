Number Extraction v0.8.0 · Windows x64 preview

- Download `NumberExtraction-0.8.0-Windows-x64.exe` and double-click it. No Python, Node.js installation, local server or separate browser is required. The first launch extracts the bundled runtime into a temporary directory.
- Windows 10/11 x64. This preview is unsigned; Windows can show an unknown-publisher prompt. Keep Windows security protections enabled.
- F11 or Alt+Enter switches fullscreen. Closing an unsettled raid asks for confirmation.
- Progress stays in `%APPDATA%\NumberExtraction` across updates. Browser progress is separate: run the v0.8 web build at the same URL used previously, open **存档**, export JSON, then import it in the desktop version. Imports show a preview and back up the existing desktop progress before replacing it.
- The UI now uses restrained tactical panels, fluorescent combat signals, separate shelter tabs and a dedicated boss health bar. v0.7 gameplay rules are retained.
- The build includes automated Windows startup, live Canvas/raid input, pause, restart persistence and portable-EXE checks. Screenshots show the tested application. Long-session performance, sound quality and different Windows display settings still need player testing.
