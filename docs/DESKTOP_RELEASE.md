Number Extraction v0.11.0 · Run Depth · Windows x64 preview

- Ten optional run modifiers, up to three per raid. Configure risk and settlement rewards before deployment: doubled enemy numbers, no dodge, fog, faster heat, glass firepower, faster movement, scarce healing, shorter time, laser jamming and warned corpse explosions. No modifiers are selected by default; equipment attributes remain intact.
- Heat grows with active raid time, kills, crates and operation nodes. Levels at 25/50/75/100 attract warned hunter squads. Hunters are capped at 12 alive/pending and 120 scheduled per raid; safehouses cancel pending hunters. Ordinary wilderness patrols remain sparse. Rewards apply at extraction, without increasing field trading currency.
- Number identity at 64, 256 and 1024: larger collision bodies and distinct movement/defence tradeoffs. Growth waits for enough space beside walls. Dash distance and existing low-tier damage examples are preserved.
- Seeded extraction conditions: timed windows, a key-card route and either a required number or a guarding boss. The western fallback opens normally and stays available. A marked forward cache supplies a key card, consumed only on successful key-route extraction. Open the top-right extraction briefing to pause and inspect all four routes.
- White shelter, colourful maps, 20 weapons, 12 enchantments, nine bosses and the persistent equipment warehouse are retained. Phase 2–4 additions such as contracts, factions, new biomes and daily runs remain on the roadmap.
- Schema-5 saves use the separate v0.11 key and copy v0.10 or older progress without overwriting the original. Warehouse contents, pending items, durability and deployment selections are retained. JSON save import/export is available in the shelter.
- Download `NumberExtraction-0.11.0-Windows-x64.exe`. Finish your current raid and exit the old game before launching it. No Python, Node.js, local server or separate browser is required. F11 / Alt+Enter toggles fullscreen.
- Automated checks cover existing gameplay and the new run rules, production UI actions, save migration and collision/telegraph boundaries. This release is published only after Windows startup, seven window/zoom layouts, settings, extraction briefing, combat, inventory, restart and final portable EXE checks pass. Screenshots and SHA256 are attached. Difficulty and economy still need hands-on playtesting.
- This preview is unsigned; Windows may show an unknown-publisher prompt. Keep security protections enabled.
