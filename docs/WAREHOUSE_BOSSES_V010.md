# v0.10 · 战备仓库与九类首领

本轮将“带出装备”从资源兑换改为实际入仓，并把首领从三类扩展到九类。庇护所新增“战备仓库”和“首领图鉴”页签；出击准备可选择当前难度允许的优先首领。

## 仓库与出击循环

1. 成功撤离后，背包和装备槽内的非初始武器、护甲、镭射存入仓库，保留品质、武器等级、附魔和护甲剩余耐久。
2. 仓库初始24格，每级增加12格，共10级，最高144格。升级消耗数据币、合金，高等级也需要核心。它与增加局内装备格的“行军背包”是两项设施，已有升级保留。
3. 满仓装备进入待收区，不自动卖掉或删除。扩容或腾出空间后点击“收纳待收装备”；待收装备先入仓才能选作出击装备。
4. 选择两个武器槽、护甲和配件。未选仓库装备的槽位使用工坊基础装备；同一件装备不能同时用于两个槽位。
5. 确认出击时先保存装备出库，再开始战局。写入失败时不出库、不开始带装战局。死亡、超时或放弃会丢失已带入的装备，未带入的库存保留；再次成功撤离可带回实际剩余耐久的装备。

仓库可付数据币修理护甲；回收装备需要在游戏内确认，会获得约估值35%的数据币以及按品质计算的合金/核心。回收价值低于相应商人购入价，避免买入后原价退款套利。工坊/永久打造发放的基础装备、标记为试用品的装备不入仓、不回收。

装备入仓时不再同时兑换成数据币或材料。碎片、金币、首领核心物资仍按原规则结算；资源袋不限量的规则保留。结算报告显示本次保存的装备数量。

旧版已自动兑换成资源的装备没有保存具体属性，无法还原。原有数据币、材料、设施、打造和记录均保留；本版开始带出的装备正式入仓。

每类有三种轮换招式，半血进入强化阶段。强化会改变攻击数量、范围或节奏。普通弹丸和正面近战可尝试弹反；地面区域攻击需要走位或闪避。

## 攻击边界与反馈

- 新区域攻击有持续预警，其伤害使用相同的矩形、圆形或环带几何。冰环和坍缩只伤害环带，圆心不是整片伤害区。
- 未释放的新区域攻击被减半/眩晕等打断时取消；释放后的区域按持续时间运行，首领死亡后清除其区域和残存召唤物。
- 寒霜减速会影响实际移动，离开后很快恢复；引力牵引走碰撞流程，受遮挡约束，并中断静止搜索/撤离。安全屋不受这些牵引、减速或伤害影响。
- 新召唤物每个首领最多同时六名、全程最多十八名，全局最多同时二十四名；虫巢没有可牺牲的活虫时不能回血。
- 弹幕预警与发射共用方向数据。首领有独立颜色、符号、名称与血条，不靠换色增加数量。
