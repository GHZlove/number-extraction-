# v0.4.1 · 荧光涂鸦配色

本轮继续仅在本地保存，保留 [v0.4](EXPANSION_V04.md) 的地图、敌人、武器、存档与全部玩法规则。

## 色彩方向

明亮的街头涂鸦与墨迹风格，配合深紫黑描边、浅色纸张、彩色贴纸卡片和荧光按钮。矢量建筑与墨迹由项目自身代码绘制，无外部素材请求。

| 颜色 | 色值 | 主要用途 |
| --- | --- | --- |
| 荧光粉 | `#ff42a2` | 墨迹、部分敌人、阴影与战斗强调 |
| 青绿 | `#12ded4` | 玩家、设施、路标和界面强调 |
| 青柠绿 | `#bdff36` | 同数合成、撤离、出击按钮 |
| 亮黄 | `#ffe64d` | 能量、计时、物资和设施 |
| 紫色 | `#ac7aff` | 区域、岩石、敌人与辅助色 |
| 深墨色 | `#221a3a` | 描边、文字、暗底信息板 |
| 纸白 | `#fffbee` | 卡片、中立数字和文字 |

## 具体变化

- 庇护所：彩色建筑、地面墨点、黑描边资源卡、四种设施贴纸色、亮色难度选择和出击按钮。
- 战区：浅色分区地面、彩色道路/桥梁/植被/岩石、可见区域的墨迹装饰与击破/爆炸泼溅。
- 实体：玩家随数字成长使用青绿、青柠或亮黄；十二类敌人有不同配色，并保留名称、速度、预警、数值与形状线索。
- 物资：品质仍按白、黄、绿、蓝、紫、红；更鲜明的色值不改变倍率。武器掉落采用深底，避免白品装备消失在亮色地面上。
- HUD：保留深色读数面板；计时器为亮黄，重要按钮荧光高亮。瞄准线保留白/红含义，增加深色衬线。
- 墨迹完全属于展示层，不会减速、不影响碰撞、不修改游戏随机数。沿用减少动态效果的系统偏好。

## 验证范围

15 个模块语法/引用检查与现有 90 项测试通过。DOM/Canvas 检查使用 Node 替身，不能替代真实浏览器的布局、配色观感、触控、音效或持续帧率验证。当前没有可用真实浏览器，最终视觉仍需试玩。

启动前先关闭旧版服务窗口，解压新包后运行 `start-windows.bat`。页面若仍显示旧色调，可使用 Ctrl+F5 刷新；页脚版本应为 0.4.1。存档继续使用 v0.3/v0.4 的相同来源与键。
