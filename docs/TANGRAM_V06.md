# v0.6 · 七巧板式战区与打击反馈

## 地图与风险

三条固定竖向区域改为 **七块相连多边形**。分解来自七巧板：两大三角形、一中三角形、两小三角形、一方形、一平行四边形，再随矩形地图缩放；因此长宽比例不等时方形会拉伸为菱形。每局按种子选择八种旋转/镜像朝向之一，再随机分配风险。这里是七巧板式分区，不是拼图拖拽玩法。

拼块覆盖全图，边界没有空气墙。沿用五档地图尺寸、时限、四个出口、怪潮与庇护所存档。道路、河道、地标和桥梁跨越拼块；地面与小地图显示相同多边形边界，HUD 显示当前拼块名称和风险，跨区时出现短提示。

| 风险 | 敌人与掉落 | 附近怪潮 |
| --- | --- | --- |
| 低 | 原低风险数字、装备和箱子价值 | 基础数量与间隔 |
| 中 | 原中风险数字、装备和箱子价值；单位面积固定守卫权重 1.3 | 每波目标数量 ×1.15，间隔 ÷1.1 |
| 高 | 原高风险数字、装备和箱子价值；单位面积固定守卫权重 1.6 | 每波目标数量 ×1.3，间隔 ÷1.2 |

波次数量向上取整，仍受局部与全图数量上限约束。怪潮数量/间隔取决于玩家所处拼块，生成敌人的数字取决于实际落点的风险，出生位置仍有预警与安全距离。固定守卫按区域面积和权重分配；数量是生成目标，受障碍和放置约束，无法保证每局严格相同。

出生点、合成链和教学设施所在拼块强制低风险，其余拼块保留中/高风险并随机分配。难度选择继续叠加地图尺寸、敌人数值、怪潮参数和资源收益。敌人跨区追击不会立即换数字或改变掉落等级。

技术上，`world.sectors` 与 `world.zones` 指向同一组七块多边形；实体的 `sectorId` 记录拼块，`zone` 继续表示 0/1/2 风险。区域查询使用完整 `(x,y)`，不再仅用横坐标。落点在多边形内部抽样，再检查障碍、占用、教学保护和地图边界。

## 打击反馈

- 枪械发射有短促枪口火光与后坐，近战有挥砍反馈。
- 命中出现定向火花、伤害数字和短暂闪白/变形；护甲耗尽只提示一次破甲，击破留下散开的碎片。
- 武器的击退强度不同：冲锋枪和双刀较轻，狙击、重剑和战锤更重。连续命中的击退速度封顶，衰减后恢复移动；位移仍使用原有碰撞和边界检查，不能推穿墙。
- 狙击、霰弹、磁轨、榴弹、大剑、长枪和战锤命中时产生 16–30 毫秒停顿；固定步长下最多暂停两个模拟步。最短触发间隔 180 毫秒，防止多弹丸/多人命中反复冻结。停顿时模拟计时一同暂停。
- 停顿期间缓冲攻击、减半、修复、闪避、拾取、过载和武器槽操作，恢复后消费一次；移动、瞄准优先采用当前输入。
- 镜头震动按命中、破甲、爆炸和击破区分强度；系统开启“减少动态效果”时不震动、不闪白变形。火花、文字与碎片仍保留。

这些反馈不改变已约定的数字伤害比例、品质倍率、护甲吸收、霰弹/连发共享伤害和原有墙体遮挡。

## 音效

仍然默认静音，点击局内右上角音效开关启用。使用本地 Web Audio 合成枪械、近战、命中、破甲、爆炸与击破音效，无新增音频下载。

不同武器有不同噪声包络和音调；命中/击破等事件限频，避免密集怪潮每次伤害都创建声音。复用 AudioContext 和短噪声缓冲；音频不可用时游戏仍可继续。音量与声音辨识度尚需实际设备听感验收。

## 验证与试玩

2026-11-04，Node.js 24.19.0：18 个模块语法/引用检查、118 项自动测试通过。新增 12 项覆盖八种朝向完整铺图、多边形抽样、种子复现、五档难度实体/风险归属、局部怪潮差异、伤害比例、破甲单次事件、墙前击退、停顿限频与操作保留、特效绘制、减少动态效果，以及音频开关/差异/限频/降级。

自动化使用 Node 的 DOM/Canvas/Web Audio 替身，不能证明实际布局、音质、手机表现或 FPS。本轮尚未执行真实浏览器和真机验收。建议试玩：

1. 连开几局，对比七块地图朝向和风险颜色，跨斜边查看 HUD 与小地图是否一致。
2. 从低风险进入中/高风险，观察数字、怪潮密度和箱子收益，再检查四出口路线。
3. 试用前沿箱中的战锤和榴弹，以及背包里的不同枪械；比较后坐、火花、破甲和击破。
4. 重击命中时连续移动、按 Q、切槽，检查操作连贯；靠墙攻击检查敌人不会被推出地图或穿墙。
5. 开音效试听持续射击、重击和密集击杀；再开启系统减少动态效果偏好并重新载入，检查镜头稳定。

完整历史测试范围见 [TESTING.md](TESTING.md)。
