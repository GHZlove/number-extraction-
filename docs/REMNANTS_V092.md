高数字阶段，低等级敌人的残骸不再只是无法合成的方块；靠近后会回收为局内金币。碎片、金币和材料也不再挤占装备背包，保留武器选择与换装的容量限制。

## 残骸如何处理

击败敌人后留下带标记的数字残骸。只有敌人残骸参与回收，普通中立数字不会被误收成金币。

| 玩家与残骸 | 行为 |
| --- | --- |
| 同数且未达到2048 | 优先合成，保留原有回血、能量和连携奖励 |
| 残骸数字低于玩家 | 靠近后自动回收为金币 |
| 残骸数字高于玩家 | 保留，成长后可以合成或回收 |
| 玩家与残骸均为2048 | 已无法继续合成，回收为金币 |

普通回收范围为56个世界单位；牵引节点生效时扩大到220。墙体仍阻挡拾取。可回收残骸显示金色轮廓和金币角标，接近时提示价值。每份残骸只能合成或回收一次，不会同时获得两种奖励。

## 收益与交易

金币原始价值为 `4 + 2 × log2(残骸数字)`：

| 残骸数字 | 金币 |
| --- | --- |
| 2 | 6 |
| 16 | 12 |
| 64 | 16 |
| 512 | 22 |
| 2048 | 26 |

金币先计入本局携带资源，可在商人处消费。交易优先花残骸金币，再花原有碎片物资，减少消耗可兑换材料的物资。未消费的金币随成功撤离一起入库，并使用现有难度和回收中心收益倍率；按整局携带价值统一取整。

金币仅提供数据币，不额外产出合金或核心。原有敌人掉落和首领物资继续按原规则结算。死亡、超时或放弃时丢失未带出的局内收益，已有庇护所资产保留；重复结算不会重复加钱。

## 装备格与资源袋

- 只有背包中的武器、护甲和镭射配件占装备格。已装备物品仍使用独立装备槽。
- 碎片、金币和材料不限格数；修复剂、减半道具仍直接补充相应计数。
- 装备满包时，仍能自动拾取资源、搜索普通箱/装备箱/首领箱和获得补给。箱内装备留在地上，腾出格子后再按F拾取。
- B背包顶部展示资源袋，按资源类别汇总数量与价值；下方装备背包保留逐件换装、丢弃和容量显示。
- HUD和商人界面的容量判定只统计装备。储备仓原有升级保留，每级继续增加两格装备容量。

内部保留资源的独立拾取记录，维持原有材料取整和首领奖励规则；界面汇总展示，避免大量碎片生成数百行列表。资源袋不限格数，不表示跨局装备仓库或自动云存档。
