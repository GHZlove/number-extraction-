# 测试说明 · v0.2

## 自动检查

需要 Node.js 22 或更新版；本轮在 Node.js 24.19.0 验证。测试无第三方依赖：

```bash
node tools/check.mjs
npm test
```

也可以显式运行全部三个测试文件：

```bash
node --test tests/game.test.js tests/combat-v02.test.js tests/browser-contract.test.js
```

本轮验证结果：**11 个 JavaScript 模块通过语法与本地引用检查；54 项测试通过。**

| 文件 | 数量 | 范围 |
| --- | --- | --- |
| `tests/game.test.js` | 19 | 合成、战斗基础、视线、移动、搜索、撤离、失败、存档与地图抽样 |
| `tests/combat-v02.test.js` | 28 | 用户示例比例、六档品质、双方碰撞、护甲耗损、六种武器、方向攻击、连续弹道、换装、结算、敌人攻击与地形减速 |
| `tests/browser-contract.test.js` | 7 | 输入释放、触控指针、屏幕坐标转换、渲染调用、装备 HUD、背包与启动流程的 Node 契约检查 |

地图测试覆盖 100 个种子的安全位置和 25 个种子的出口网格可达性，不是对所有种子的证明。契约测试使用 DOM/Canvas 测试替身，不包含真实布局、原生事件默认行为、触屏硬件、音频、GPU 性能或浏览器兼容性验证。

## v0.2 人工试玩清单

1. 启动、开始、移动、合成、暂停、失焦、打开/关闭 B 背包。
2. 鼠标四向瞄准，四类枪械的弹道与墙体遮挡，大剑/双刀的前后与范围判定。
3. 开装备箱，连续三次 F 拾取，分别装武器槽 1/2、护甲和镭射；满包换装、收回和丢弃。
4. 对照白色、无护甲的 8↔4 与 16↔4 比例，再验证品质加成、护甲耗损及损坏后的伤害。
5. 对比白线与红线，以及镭射对冲锋枪实际散布的收缩。
6. 观察六种敌人的预警、散射、狙击、冲锋和爆破；验证 ÷2 打断及闪避免伤。
7. 水洼/泥地减速、两出口路线、多随机地图和长时间游玩。
8. 撤离后检查装备兑换价值仅入账一次；死亡保留基地；新局只有初始白色武器；旧版余额和升级正常读取。
9. 桌面 Chrome/Firefox/Safari、手机横竖屏、触屏多点操作与低性能设备表现。

详细玩法和边界见 [v0.2 战斗规则](COMBAT_V02.md)。以上真实浏览器/设备项目在本轮环境中尚未执行。

## v0.1 历史人工验收清单

以下为旧版记录，涉及自动锁定攻击的内容已由 v0.2 方向攻击替代。

每一步使用游戏实际控件，不修改运行时状态。

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开页面 | 起始界面、地图背景、开始按钮，无空白画面 |
| 2 | 点击开始，WASD 或方向键移动 | HUD 与世界位置更新，镜头跟随，无法出界 |
| 3 | 按教学路线碰 1、2、4 | 玩家依次变为 2、4、8，合成提示出现 |
| 4 | 用较大玩家碰低数字，或用低数字碰高数字 | 不合成、不塞进背包 |
| 5 | 靠近追猎者 | 敌人追踪，先显示红圈，随后攻击固定位置 |
| 6 | 靠近哨戒者 | 显示虚线，再发射弹丸，侧移可以避开 |
| 7 | 按 Q，再按空格攻击 | ÷2 数量减少一次，敌人减半并眩晕，攻击伤害随关系改变 |
| 8 | 墙后攻击或 Q | 不隔墙生效；无有效目标的 Q 不耗道具 |
| 9 | Shift 冲向墙 | 不穿墙；闪避冷却显示；空地可短暂躲避伤害 |
| 10 | 损血后按 R；满血再尝试 | 第一次回血并耗药，满血时不耗药 |
| 11 | 在教学箱旁静止按住 E | 搜索完成，背包增加 1，价值为 24 |
| 12 | 满包后开箱或踩掉落 | 不超容量，未拾取物资仍在 |
| 13 | 西侧绿圈按 E 2 秒后松开 | 撤离进度清零 |
| 14 | 重新按住 E，期间移动或受伤 | 撤离进度清零 |
| 15 | 绿圈连续静止按住 E 4 秒 | 成功结算，带出价值加到基地余额 |
| 16 | 打开关闭结果或仓库页面 | 不重复加钱 |
| 17 | 再开一局，带物资后死亡 | 结果显示损失，仓库既有余额保留 |
| 18 | Esc 暂停，再切换窗口 | 计时和敌人停止，返回后需继续；不粘键 |
| 19 | 成功后刷新页面 | 已结算余额和升级仍在；不会恢复进行中的行动 |
| 20 | 购买升级，开始下一局 | 背包/开局道具改变，数字仍从 1 开始 |
| 21 | 触屏浏览器横竖屏，按住 E 并操作摇杆 | 控件无遮挡、多点触控正常、取消触控能归零 |
