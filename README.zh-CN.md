# 数字进化 · Number Extraction v0.7.0

**合成数字，启动过载，带资源撤离，建设庇护所。**

一款将 **2048 同数合成**融入探索、战斗与撤离的单机游戏。每局从数字 **1** 开始，在程序生成的战区里成长、换装，借助减半运算和技能挑战更强的敌人，再决定何时带着物资返回。成功撤离的资源用于建设庇护所，让下一次出击更有准备。

项目使用原生 **JavaScript ES modules、HTML5 Canvas、CSS、Web Audio 与 localStorage** 实现，无第三方运行依赖。技术展示重点包括玩法系统设计、状态管理、程序地图、碰撞几何、空间查询、存档迁移和自动化验证。

当前为 **v0.7.0 可玩原型**，包含四种地图、据点守卫、打造与四种附魔、十四类武器、十二类敌人、三种首领和五档难度，已通过 147 项自动测试。英文 README 面向项目评审与作品集展示；游戏界面目前为简体中文。

## 这一版的变化

- **据点守卫为主**：大部分敌人集中在资源点，野外只刷新少量巡游敌人，附近巡游最多十名。据点存活守卫可呼叫有限增援，清空后不再持续增援；守卫被拉远会返回。
- **四种地图**：七巧遗迹、裂谷放射、补给街区、多心荒原，出击前可选或随机。区域数量为7–12块，布局、地标顺序、河道与风险会变化。
- **枪械击退**：枪种、双方数字差、武器品质和Lv.等级共同影响；狙击比冲锋枪击退更强。重装敌人和首领具有抗性，击退仍受墙体约束。
- **四种附魔**：吸血、连锁闪电、眩晕、毒雾。掉落和商人可提供附魔装备，前沿试验箱提供四种附魔供早期体验。
- **永久打造**：在庇护所打造当前出击武器，最高Lv.5，每增加一级伤害+8%并提高击退。升级可重选附魔，满级可付费重铸。每局重新发放打造武器，死亡不丢打造记录，发放装备不可兑换资源。
- **野外商人**：西侧安全屋旁按E交易，用背包物资购买修复剂、减半道具、护甲、镭射或闪电步枪；库存每局有限。
- **三类首领**：裂地巨像、棱镜督军、瘴雾女王，具备震地、冲锋、弹幕、环射、毒雾或增援，半血进入第二阶段；击败后出现高价值物资箱。
- **安全屋与守门首领**：低风险出口有保护圈，每处每局回复25生命并修补15护甲，屋内禁止攻击；部分高风险出口需击败对应首领后撤离。
- **右键弹反**：朝向攻击方向，右键或C触发0.18秒判定，成功可反射弹丸或打断近战；不能长按防御，毒雾和普通爆炸不可弹反。

保留全屏战局、荧光涂鸦配色、五档难度、2048合成、过载、运算节点、庇护所升级和原有十四类武器。

## 快速启动

[下载 v0.7 完整试玩 ZIP](https://github.com/GHZlove/number-extraction-/archive/refs/heads/feature/strongholds-forge-v07.zip)。此版本位于独立试玩分支，主分支和线上游戏按各自发布进度更新。

需要 Python 3 和现代浏览器，无第三方依赖、无构建步骤。解压完整 ZIP 后，Windows 双击 `start-windows.bat`，保留命令窗口，打开 **http://localhost:8000**。

Windows 也可在项目根目录运行：

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

没有 `py` 时改为 `python`。macOS / Linux 使用：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

在庇护所选择难度和出击武器，点击 **确认出击**。不能直接双击 `dist/index.html`；模块需要 HTTP 服务。退出服务按 Ctrl+C。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 左键 / 空格 | 持续射击或挥砍 |
| 右键 / C | 朝向来袭方向，短窗口弹反 |
| 1 / 2 | 切换武器槽 |
| F | 拾取附近装备 |
| B | 背包换装、切换或丢弃，期间暂停 |
| G | 满能量启动过载 |
| Q | 敌人数值减半、打断并眩晕 |

触控界面有摇杆和动作按钮，可在背包中切换武器；手机真机和 Safari 尚待验证。音效默认关闭。

## 第一局建议

1. 向右合成固定的 1、2、4、8，成长到 16，能量充满。
2. `(485,1190)` 的教学箱提供价值 24 的物资和一个 ÷2，静止按 E 0.75 秒。
3. `(620,1260)` 的装备箱提供黄品步枪、白品护甲和镭射；F 拾取，B 换装。
4. 对附近追猎者尝试 G 过载、Q 运算和 Shift 闪避，也可以绕开。`(1180,1270)` 有增幅节点。
5. `(1500,1420)` 的前沿试验箱提供吸血卡宾枪、毒雾榴弹、闪电长枪、眩晕战锤，方便直接试用。
6. 等待撤离开放（最低难度45秒），回到 `(310,530)` 西侧绿色出口，静止按 E 四秒，受伤、移动或松键会中断。
7. 结算直接回庇护所，资源足够时升级设施，再次出击。

数字上限仍为 2048；高难度精英敌人可超过此上限。白色Lv.1无附魔、无增益、无护甲时，8 打 4 为对方最大生命的 50%，4 打 8 为 25%；16 打 4 为 75%，4 打 16 为 12.5%。品质按白/黄/绿/蓝/紫/红分别乘 1/1.2/1.4/1.6/1.8/2，护甲、过载、节点再影响最终结果。

## 存档和范围

v0.7 将 v0.3–v0.6 的庇护所和资源自动迁移到独立存档，保留原存档；旧版不会覆盖新版打造记录。请使用相同浏览器和完全相同的网址（localhost与127.0.0.1的进度不共用）。存档仅属于当前浏览器与来源，本地和线上不共享。清理浏览器数据会清空进度，多开标签可能互相覆盖；刷新不会保存未结束的战局。

拾取装备成功撤离后兑换资源，工坊基础装备每局重新发放且不可出售；本轮没有跨局装备仓库。死亡、超时或放弃不带出局内收益，保留已有庇护所资产。

当前版本通过 21 个模块静态检查和 147 项自动测试。自动测试中的 DOM/Canvas/Web Audio 使用替身，不等于真实浏览器、视觉、触控、音质或帧率验收；长时间游玩与经济平衡仍需试玩反馈。
