# 数字进化 · Number Extraction v0.2

**2048 同数合成 × 武器换装 × 数学战斗 × 搜打撤。**

[English](README.md) · [v0.2 武器、碰撞与地形](docs/COMBAT_V02.md)

本版增加六种武器、白黄绿蓝紫红六档品质、护甲耐久、镭射瞄准、碰撞互伤、复杂地形与六种敌人攻击机制。

从数字 1 出发，找到同数进化，用 ÷2 和闪避应对敌人，搜集物资，再到绿色出口按住 E 撤离。战利品只有成功撤离才进入基地。

## 快速启动（Windows）

本机运行只需要 Python 3 和现代浏览器。无需安装 npm 包。先将完整压缩包解压到一个目录，不能只取 `index.html`。

方法 A：双击项目根目录的 `start-windows.bat`。保持终端窗口打开，在浏览器访问 `http://localhost:8000`。

方法 B：VS Code 打开项目根目录，在终端执行：

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

如果电脑没有 `py` 命令，但 Python 已在 PATH 中：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Linux / macOS：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

打开 `http://localhost:8000`，点击“开始行动”。停止服务按 Ctrl+C。如果 8000 端口被占用，把命令和浏览器地址同时改成 8001。

**不要直接双击 `dist/index.html`。** 这版采用 ES modules，应该通过本地 HTTP 服务运行。服务器只是提供静态文件，所有游戏模拟都发生在浏览器里。

## 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标移动 | 瞄准方向 |
| 空格 / 鼠标左键 | 沿瞄准方向攻击；按住可连续攻击 |
| 1 / 2 | 切换两把武器 |
| F | 拾取附近装备 |
| B | 暂停并打开装备背包，可换装、收回或丢弃 |
| Q | 消耗一次 ÷2，削弱并打断目标 |
| Shift | 向移动方向闪避，短暂无敌 |
| E（按住） | 静止搜索箱子 / 在绿色出口撤离 |
| R | 消耗修复剂，恢复 30 生命 |
| Esc | 暂停 / 继续 |

触屏设备会显示虚拟摇杆与对应按钮。触屏界面已实现，iPhone 真机操作、浏览器横竖屏和长时间性能仍需进一步验收。

## 第一局建议路线

1. 出生后向右走，依次碰到 1、2、4，成长到 8。第三个数字稍微在上方。
2. 回到出生点右下方的补给箱附近，静止按住 E 约 0.75 秒，得到价值 24 的物资及一个 ÷2。
3. 在 `(620,1260)` 的装备箱静止按 E 开箱。逐次按 F 拾取黄品突击步枪、白品护甲与镭射，按 B 装配，1/2 切换。
4. 想战斗：箱子右侧有一个数字 8 追猎者，先看清红圈；按 Q 削弱或 Shift 躲开，再用空格攻击。也可以直接避战。
5. 想先体验成功：向左回到出生点附近，再沿左侧向上。西侧闸门在 `(310,530)`。
6. 进入绿色圆圈，松开移动键，按住 E 连续 4 秒。查看“成功撤离”和基地余额。

首局数字链和箱子固定，其余地图每局变化。初始数字链附近不是永久无敌区，长时间停留仍可能遭到追击。死亡后不会失去已经结算的基地资产。

## 本版范围与限制

已实现角色移动、地图跟随、三档区域、同数合成、六种敌人、方向武器攻击、六档武器品质、护甲耐久、镭射瞄准、碰撞互伤、÷2、闪避、修复、搜箱、容量背包、撤离读条、死亡/超时结算、基地升级、本地存档、暂停和触屏控件。

仓库暂时是数据币与升级记录，带出的战利品自动兑换。局内装备可换装或丢弃，撤离后兑换货币，不跨局保存。没有完整装备仓库、交易、保险箱、随机词条、等级技能解锁、多人联网或云同步。只有一种数学道具，先验证它是否好玩，再扩展。

存档保存在当前浏览器同一网站来源中。清除网站数据会清除进度；私密浏览可能不保留；本地地址和在线地址各有独立存档；多标签页同时游玩可能覆盖进度。刷新/关闭不会带出正在进行的一局。

本版不含第三方付费素材和网络请求。音效可在右上角开启。后续发布前仍需要真机测试、平衡测试和足够的内容打磨。
