# 数字进化 · Number Extraction

**合成成长，搭配装备，决定何时带着收获撤离。**

《数字进化》是一款融合 **2048 同数合成、鼠标瞄准战斗与庇护所成长**的单机搜打撤原型。每次远征从数字 **1** 开始，在色彩丰富的程序地图中合成、探索和换装；随着热度升高、追猎逼近，你需要在继续搜刮与安全带出之间作出选择。

项目使用原生 **JavaScript、HTML5 Canvas、CSS、Web Audio 与 localStorage** 开发，Windows 版通过 Electron 打包为可离线运行的独立游戏窗口。工程重点包括玩法系统设计、程序地图、碰撞与导航、存档迁移，以及自动化验证。

## 项目亮点

- **数字决定战斗方式**：同数合成成长，用减半运算处理强敌；高等级数字在体型、移动和防御上产生取舍。
- **装备与路线相互影响**：双武器槽、十二种附魔、打造、野外商人和方向弹反，让远程与近战形成不同选择。
- **探索带来持续压力**：资源点重兵把守，野外巡游较少；热度与追猎让停留更有代价，特殊出口附带窗口、钥卡、数字或首领条件。
- **撤离连接长线成长**：带回资源升级庇护所，把战利品存入可扩容仓库。再次携带出击的装备有丢失风险，碎片与金币使用独立的无限资源袋。
- **反馈可以被记录和分析**：本地日志保存对局与自愿反馈，匿名JSON由玩家主动导出；临时合并分析不改存档，也不自动上传。

## 核心玩法

- **据点守卫为主**：大部分敌人集中在资源点，野外只刷新少量巡游敌人，普通巡游最多十名，热度追猎使用独立的十二名在场及待出生上限。据点存活守卫可呼叫有限增援，清空后不再持续增援；守卫被拉远会返回。
- **四种地图**：七巧遗迹、裂谷放射、补给街区、多心荒原，出击前可选或随机。区域数量为7–12块，布局、地标顺序、河道与风险会变化。
- **枪械击退**：枪种、双方数字差、武器品质和Lv.等级共同影响；狙击比冲锋枪击退更强。重装敌人和首领具有抗性，击退仍受墙体约束。
- **十二种附魔**：打造、掉落和商人使用同一套装备规则；原前沿试验箱保留四种基础附魔，新军械箱提供八种新增附魔。详细效果见 [v0.9规则](docs/BRIGHT_V09.md)。
- **永久打造**：在庇护所打造当前出击武器，最高Lv.5，每增加一级伤害+8%并提高击退。升级可重选附魔，满级可付费重铸。每局重新发放打造武器，死亡不丢打造记录，发放装备不可兑换资源。
- **野外商人**：西侧安全屋旁按E交易，用背包物资购买修复剂、减半道具、护甲、镭射或闪电步枪；库存每局有限。
- **九类首领**：保留原三类，新增六种首领；包含十字雷击、冰霜减速/扩散环、扇形近战、炮台/轰炸、引力牵引/收缩环、虫群汲取修复，半血强化。图鉴可查看应对策略，出击前可选择目标。
- **安全屋与条件撤离**：安全屋每处每局回复25生命并修补15护甲，屋内禁止攻击。热度在安全屋周边增长减半、暂停安排追猎，仍不会清零。特殊出口的门槛与开放窗口可在撤离情报查看，西侧保底无额外条件。
- **右键弹反**：朝向攻击方向，右键或C触发0.18秒判定，成功可反射弹丸或打断近战；不能长按防御，毒雾和普通爆炸不可弹反。

保留全屏战局、荧光涂鸦配色、五档难度、2048合成、过载、运算节点、庇护所升级和已有武器。

## 快速启动

[下载当前试玩网页版 / 源码 ZIP](https://github.com/GHZlove/number-extraction-/archive/refs/heads/feature/bright-arsenal-v09.zip)。此版本位于独立试玩分支，主分支和线上游戏按各自发布进度更新。

需要 Python 3 和现代浏览器，无第三方依赖、无构建步骤。解压完整 ZIP 后，Windows 双击 `start-windows.bat`，保留命令窗口，打开 **http://localhost:8000**。

Windows 也可在项目根目录运行：

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

没有 `py` 时改为 `python`。macOS / Linux 使用：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

在庇护所选择难度和出击武器，点击 **确认出击**。不能直接双击 `dist/index.html`；模块需要 HTTP 服务。退出服务按 Ctrl+C。

## 第一局建议

1. 向右合成固定的 1、2、4、8，成长到 16，能量充满。
2. `(485,1190)` 的教学箱提供价值 24 的物资和一个 ÷2，静止按 E 0.75 秒。
3. `(620,1260)` 的装备箱提供黄品步枪、白品护甲和镭射；F 拾取，B 换装。
4. 对附近追猎者尝试 G 过载、Q 运算和 Shift 闪避，也可以绕开。`(1180,1270)` 有增幅节点。
5. `(1500,1420)` 的前沿钥卡箱提供一张本局撤离钥卡，以及吸血卡宾枪、毒雾榴弹、闪电长枪、眩晕战锤，方便直接试用。
6. 前沿试验箱旁 `(1670,1500)` 的军械箱提供六种新武器与八种新附魔。F 拾取、B 换装；试用品不能换资源，装备格满时需先选择或丢弃装备。
7. 等待撤离开放（最低难度45秒），回到 `(310,530)` 西侧绿色出口，静止按 E 四秒，受伤、移动或松键会中断。
8. 结算直接回庇护所，资源足够时升级设施，再次出击。

数字上限仍为 2048；高难度精英敌人可超过此上限。白色Lv.1无附魔、无增益、无护甲时，8 打 4 为对方最大生命的 50%，4 打 8 为 25%；16 打 4 为 75%，4 打 16 为 12.5%。品质按白/黄/绿/蓝/紫/红分别乘1/1.2/1.4/1.6/1.8/2，护甲、过载、节点、数字形态及词条再影响最终结果。

## 存档和范围

v0.11.1沿用v0.11.0的存档和仓库。v0.11 使用结构5与独立 `number-extraction-v11` 存档键，优先复制v0.10，其次v0.9及更早版本；原键保留，旧版不能覆盖新进度。仓库、待收装备、选装计划和打造记录保留，旧存档默认不选择词条。桌面版存档目录保持不变，旧EXE进度可自动迁移。请先退出旧版再启动新版，避免单实例锁唤起旧窗口。请使用相同浏览器和完全相同的网址（localhost与127.0.0.1的进度不共用）。存档仅属于当前浏览器与来源，本地和线上不共享。清理浏览器数据会清空进度，多开标签可能互相覆盖；刷新不会保存未结束的战局。

本版开始，拾取装备成功撤离后入仓，不再同时兑换成资源；工坊基础装备每局重新发放且不入仓/出售。死亡、超时或放弃丢失本局携带装备和收益，未带入的仓库及已有庇护所资产保留。旧版已兑成资源的装备无法还原，已有资源保留。

v0.11.3的355项自动测试、Windows原生首启/重启与最终便携EXE检查通过；实际下载已核对SHA256和MZ/PE格式，结果见 [测试记录](docs/TESTING.md)。逻辑测试中的 DOM/Canvas/Web Audio 使用替身；Windows工作流另行检查真实启动、白底主页、12格数字预览、出击按钮、移动合成、暂停、重启存档，以及临时报告导入和存储隔离，并附截图。长时间游玩、音质、硬件性能与经济平衡仍需试玩反馈。
