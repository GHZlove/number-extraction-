# 数字进化 · Number Extraction v0.4

**合成数字，启动过载，带资源撤离，建设庇护所。**

一款将 **2048 同数合成**融入探索、战斗与撤离的单机游戏。每局从数字 **1** 开始，在程序生成的战区里成长、换装，借助减半运算和技能挑战更强的敌人，再决定何时带着物资返回。成功撤离的资源用于建设庇护所，让下一次出击更有准备。

项目使用原生 **JavaScript ES modules、HTML5 Canvas、CSS、Web Audio 与 localStorage** 实现，无第三方运行依赖。技术展示重点包括玩法系统设计、状态管理、程序地图、碰撞几何、空间查询、存档迁移和自动化验证。

当前为 **v0.4 可玩原型**，包含十四类武器、六档品质、十二类敌人、五档难度，已通过 90 项自动测试。英文 README 面向项目评审与作品集展示；游戏界面目前为简体中文。

## 这一版的变化

- **全屏战局**：移除局内左侧基地栏，只保留画面内 HUD、小地图和操作提示。
- **独立庇护所**：战局结束直接返回；使用数据币、合金和核心升级储备仓、补给站、武器工坊、回收中心。
- **五档难度**：出击前选择难度和工坊武器，地图、敌人数字、时限、资源收益随难度提升。
- **地图长宽各为最初版本的 10 倍起步**：最低 32000 × 20000，面积 100 倍；最高 64000 × 40000，面积 400 倍。五档时限为 10/12/14/16/18 分钟。
- **合成过载**：同数合成积累能量，满能量按 G，七秒内强化伤害与攻击速度，并震慑周围敌人。
- **运算节点**：按住 E 激活，获得增幅、相位减伤或牵引拾取范围增益，每个节点每局使用一次。
- **十四类武器**：新增脉冲卡宾枪、轻机枪、复合弩、榴弹发射器、长枪和战锤，连发、穿透、范围爆炸和打断各有用途。
- **十二类敌人**：新增疾行斥候、重装巨像、游击射手、修复者、孵化者、环射守卫。不同类型与个体有不同移速，支持治疗、召唤、三连发与环射。
- **复杂地形**：工业庭院、集装箱巷道、岩脊、河湾栈桥、隐蔽林地、中继站；浅水、泥地减速，公路桥面加速，灌木降低远处敌人的警觉。新增两处撤离点。
- **新 UI**：深蓝与薄荷绿界面、设施插画、资源卡片、出击准备与结算报告。

## 快速启动

需要 Python 3 和现代浏览器，无第三方依赖、无构建步骤。解压完整 ZIP 后，Windows 双击 `start-windows.bat`，保留命令窗口，打开 **http://localhost:8000**。

Windows 也可在项目根目录运行：

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

没有 `py` 时改为 `python`。macOS / Linux 使用：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

在庇护所选择难度和出击武器，点击 **确认出击**。不能直接双击 `dist/index.html`；模块需要 HTTP 服务。退出服务按 Ctrl+C。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 左键 / 空格 | 持续射击或挥砍 |
| 1 / 2 | 切换武器槽 |
| F | 拾取附近装备 |
| B | 背包换装、切换或丢弃，期间暂停 |
| G | 满能量启动过载 |
| Q | 敌人数值减半、打断并眩晕 |
| Shift | 闪避，短暂无敌 |
| 按住 E | 静止搜索、激活节点或撤离 |
| R | 修复 30 生命 |
| Esc | 暂停 / 继续 |

触控界面有摇杆和动作按钮，可在背包中切换武器；手机真机和 Safari 尚待验证。音效默认关闭。

## 第一局建议

1. 向右合成固定的 1、2、4、8，成长到 16，能量充满。
2. `(485,1190)` 的教学箱提供价值 24 的物资和一个 ÷2，静止按 E 0.75 秒。
3. `(620,1260)` 的装备箱提供黄品步枪、白品护甲和镭射；F 拾取，B 换装。
4. 对附近追猎者尝试 G 过载、Q 运算和 Shift 闪避，也可以绕开。`(1180,1270)` 有增幅节点。
5. `(1500,1420)` 的前沿试验箱提供卡宾枪、榴弹发射器、长枪、战锤，方便直接试用。
6. 回到 `(310,530)` 西侧绿色出口，静止按 E 四秒，受伤、移动或松键会中断。
7. 结算直接回庇护所，资源足够时升级设施，再次出击。

数字上限仍为 2048；高难度精英敌人可超过此上限。白色无增益、无护甲时，8 打 4 为对方最大生命的 50%，4 打 8 为 25%；16 打 4 为 75%，4 打 16 为 12.5%。品质按白/黄/绿/蓝/紫/红分别乘 1/1.2/1.4/1.6/1.8/2，护甲、过载、节点再影响最终结果。

## 存档和范围

v0.4 继续使用 v0.3 存档，保留庇护所与资源；更早版本首次自动迁移，原存档保留。存档仅属于当前浏览器与来源，本地和线上不共享。清理浏览器数据会清空进度，多开标签可能互相覆盖；刷新不会保存未结束的战局。

拾取装备成功撤离后兑换资源，工坊基础装备每局重新发放且不可出售；本轮没有跨局装备仓库。死亡、超时或放弃不带出局内收益，保留已有庇护所资产。

当前版本通过 15 个模块静态检查和 90 项自动测试。自动测试中的 DOM/Canvas 使用替身，不等于真实浏览器、视觉、触控、音效或帧率验收；长时间游玩与经济平衡仍需试玩反馈。

